Automação de Dados Geoforce

Python PyInstaller Manipulação de PDF

Desenvolvimento de uma aplicação desktop em Python (compilada como executável com PyInstaller) para automatizar o processamento de certificados de inspeção em formato PDF. O script extrai os dados e sincroniza as atualizações de conformidade dos equipamentos diretamente na plataforma Geoforce. Essa solução eliminou a entrada manual de dados, reduzindo drasticamente o tempo operacional e mitigando falhas humanas no processo de qualidade.

Integração de Checklists Geoforce

Power Automate Python Microsoft Teams

Desenvolvimento de um ecossistema automatizado utilizando Power Automate e Python para o fluxo de checklists de inspeção. A solução utiliza o Power Automate para monitorar o Microsoft Teams, capturando novos PDFs e acionando feedbacks automáticos via reações. Em seguida, uma aplicação Python (com interface gráfica e lógica de validação) processa os certificados (como DNV e DPC) e sincroniza instantaneamente informações de conformidade, dados de GPS e regras complexas de compartilhamento de clientes (como Clariant e Champion) diretamente na plataforma Geoforce. O projeto eliminou a dependência de processos manuais, garantindo rastreabilidade e extrema precisão técnica.

Sistema de Ordens de Serviço

JavaScript HTML/CSS Lógica de Workflow

Desenvolvimento de lógicas e ferramentas de workflow utilizando JavaScript com foco no controle de ordens de serviço de equipamentos. O projeto aplica fundamentos de desenvolvimento web full-stack para criar fluxos consistentes que otimizam a criação, o acompanhamento e o fechamento de requisições técnicas de manutenção.
