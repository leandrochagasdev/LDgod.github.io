Automação de Dados Geoforce
Python PyInstaller

Desenvolvimento de uma aplicação desktop em Python (compilada como executável) para automatizar o processamento de certificados de inspeção em formato PDF. O script extrai os dados e sincroniza as atualizações de conformidade diretamente na plataforma Geoforce, eliminando entrada manual e reduzindo tempo operacional.

Integração de Checklists
Power Automate Python MS Teams

Solução automatizada onde o Power Automate monitora o MS Teams capturando PDFs. Um script Python processa os certificados (DNV e DPC) e sincroniza informações de conformidade, GPS e regras de compartilhamento de clientes (Clariant, Champion) direto na plataforma, garantindo extrema precisão técnica.
